Model Architectural Paradigms: CNN, BiLSTM, Transformers & Fusion
Full Deep Learning Suite

How spatial-temporal ECG representations and tabular clinical variables are modeled across distinct neural paradigms:

CNN

Multi-Scale 1D CNN

Applies parallel convolution kernels (3, 7, 15) to capture localized morphological transients, sharp QRS complexes, and P/T wave deflections.

Local Receptive Field Shift Invariant GELU Activation
LSTM

Bidirectional LSTM

Dual-directional recurrent gates capture temporal progression and rhythmic beat-to-beat cardiac cycle patterns in forward and reverse sequence.

Bidirectional Memory Rhythm Dynamics Hidden Dim: 64
TF

Self-Attention Transformer

Tokenizes 12-lead signals into 50ms temporal patches with Sinusoidal Positional Encodings and Multi-Head Self-Attention for global context.

Multi-Head (4 heads) Positional Encoding O(1) Path Length
FUS

Gated Multimodal Fusion

Computes dynamic scalar gating factor based on input confidence: g = σ(W_g [z_ecg; z_clin] + b). Prevents modality collapse.

Adaptive Confidence Non-linear Gating Audit Telemetry
